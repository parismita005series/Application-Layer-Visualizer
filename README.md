# Application Layer Visualizer

A web-based application designed to visualize and simulate important **Application Layer protocols** of Computer Networks.

The project provides an interactive way to understand how protocols such as **DNS, HTTP, and SMTP** work through visual simulations.

---

## 🚀 Features

- 🌐 **DNS Simulation**
  - Visualizes the process of domain name resolution.
  - Shows the interaction between client and DNS server.

- 🌍 **HTTP Simulation**
  - Demonstrates HTTP request and response communication.
  - Helps understand how a web client communicates with a server.

- 📧 **SMTP Simulation**
  - Visualizes the process of sending emails using SMTP.
  - Shows communication between mail client and mail server.

- 🎨 **Interactive Web Interface**
  - Simple and student-friendly interface.
  - Visual representation of protocol communication.
